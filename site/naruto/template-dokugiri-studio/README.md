# Studio Dokugiri

Studio independente para Genryuusai, com assets locais, editor e exportação de template HTML/CSS.

Pasta publicada futura: /naruto/template-dokugiri-studio/

O rascunho usa somente nsc:dokugiri-template-studio:draft:v1 e nsc:dokugiri-template-studio:jutsus:v1. Nenhuma dependência do Bonds App, Skin 2.0, loader ou Studio Saga.

Execute npm run build na raiz. Para revisar, sirva dist/ por HTTP e abra a pasta acima. Nenhum script precisa ser instalado no fórum: gotas e abas usam CSS e HTML. O texto usa Arial 13px, com itálico entre asteriscos, espaços preservados e contador de palavras.

O exportador usa URLs absolutas de imagens em https://digimon-bonds.github.io/naruto/template-dokugiri-studio/assets/. Elas estarão disponíveis após a publicação deste projeto. A exportação pressupõe HTML habilitado no fórum.

As quatro técnicas especializadas da ficha foram consultadas em 11/11/2026. O Studio permite importar uma lista JSON de jutsus para atualizar o catálogo. A capa inicial é texto demonstrativo editável.
