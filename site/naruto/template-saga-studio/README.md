# Template Saga Studio

Projeto estático independente. Abra index.html ou sirva esta pasta por HTTP.

URL após publicação autorizada: https://digimon-bonds.github.io/naruto/template-saga-studio/

O build copia site/ recursivamente para dist/. Não requer alteração do build, do aplicativo Bonds, da Skin 2.0 ou do loader do fórum.

Armazenamento exclusivo: nsc:saga-template-studio:draft:v1 e nsc:saga-template-studio:jutsus:v1. Não lê nem migra dados do Bonds ou do Studio local antigo.

CSS do Studio em studio.css e comportamento em studio.js. O CSS exportado do post permanece embutido no index.html, para preservar a geração do template. Ícones, glifos e efeitos são incorporados no próprio projeto. O retrato mantém a URL externa usada pelo Studio original, sem compartilhar assets do Bonds.

O catálogo inclui os três jutsus Rank B publicados na ficha de Saga, conferidos em 11/11/2026. Campos e descrições foram preservados como publicados, inclusive os campos vazios de Correntes Sifonadoras. A atualização continua disponível pela importação do pergaminho existente.
