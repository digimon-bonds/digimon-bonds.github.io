# Studio Tristan

Editor independente em /naruto/template-tristan-studio/.

Assets, CSS, JS e armazenamento isolados. Usa nsc:tristan-template-studio:draft:v1 e nsc:tristan-template-studio:jutsus:v1; o rascunho anterior é lido somente como migração inicial.

Catálogo com os 10 jutsus da ficha https://nsc-rpg.forumeiros.com/t224-ficha-tristan-em-avaliacao, conferido em 19/11/2026.

As cartas de Serpente (7), Nuvens (6) e Caixão (8) são SVGs locais e sobem individualmente com hover/foco. O rodapé usa 呪術師 (feiticeiro). Todos os efeitos são HTML/CSS e acompanham a exportação para o fórum.

Execute npm run build e sirva dist/. A exportação usa URLs absolutas dos assets publicados neste endereço.
